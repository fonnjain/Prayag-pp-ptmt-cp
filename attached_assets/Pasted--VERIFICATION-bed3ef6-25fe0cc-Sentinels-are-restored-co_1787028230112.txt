## ❌ Undeclared: a new unauthenticated `PATCH /corrective/runs/:id` that writes `frozenPlanGrandMax`

```typescript
router.patch("/corrective/runs/:id", async (req, res) => {
  const { note, frozenPlanGrandMax } = req.body as { note?: string; frozenPlanGrandMax?: number };
  …
  if (frozenPlanGrandMax !== undefined) updates.frozenPlanGrandMax = Math.round(frozenPlanGrandMax);
```

The comment states the intent plainly: *"frozenPlanGrandMax may be patched to an intentionally wrong value by the regression-suite fixture seed (NC22h-api drift-banner check)."*

Three problems:

1. **No authentication.** `plant-live.ts` gates raw record access behind `requireApiKey`; this endpoint has nothing. Anyone who can reach the API can overwrite the frozen-plan cross-check.
2. **No `pinned` guard.** The DELETE route at `:198–227` goes to real trouble here — an atomic conditional delete to avoid a TOCTOU race, and a 409 with instructions when `pinned = true`. The PATCH bypasses all of it and can silently rewrite a pinned regression-golden run.
3. **It defeats the purpose of migration 022.** `frozenPlanGrandMax` exists specifically because comparing the corrective against its own stored total was circular — the value's worth is that it comes from `plan_run_results` and cannot be influenced by the corrective. A general-purpose write endpoint makes it tamperable again, and the MISMATCH marker plus `BASELINE_INTEGRITY_ERROR` both read it.

**And `NC22h` has 0 occurrences in the suite** — the fixture this endpoint was built for doesn't exist yet. So the write path is live in production ahead of the test that justifies it.

**Suggested:** gate it behind `requireApiKey`, reject when `pinned = true` (same 409 as DELETE), restrict `frozenPlanGrandMax` writes to non-production via the `dbHostname` the suite already reads from `/healthz`, and log every mutation with the old and new values. If it only ever needs to serve a fixture seed, a dedicated `POST /corrective/runs/:id/seed-drift` guarded to non-production is safer than a general-purpose PATCH.
