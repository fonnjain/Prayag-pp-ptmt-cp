# Replit Prompt — Scope the "No Google Sheets" Rule to PLANNING Only

Clarifying an existing rule so it is applied correctly and consistently.

## The rule, scoped

**PLANNING must use UPLOADED FILES ONLY. No Google Sheet may be read anywhere in the plan-build path.**

Planning inputs (uploads only):
- **PTMT:** FG Stock file, last-month pending file, DATA.xlsx
- **Plumbing:** FG Stock file, DATA.xlsx

The plan must be **computed** from these inputs — never copied from, or reconciled against, a master planning sheet.

**Everything OUTSIDE planning may continue to read Google Sheets** (unchanged, keep working):
- Production **monitoring** actuals — PTMT ANUJ `Production` tab; Plumbing `Sheet3`
- **Corrective re-plan** production-to-date (same sources)
- **BOM weights** for kg (Plumbing Material BOM)
- **Machine capacity** reference data

Rationale: the plan is the authoritative output this app produces, so its inputs must be controlled and reproducible. Actuals and reference data are observations from elsewhere and may stay live.

---

## What to do

1. **Audit the plan-build path** (both segments) and confirm no Google Sheet is read anywhere in it — including any fallback, cache-miss, retry, or "if upload missing then…" branch. Report every data source the plan touches, with its origin (upload vs sheet).

2. **Remove any silent fallback to a sheet in planning.** If a required upload is missing, the plan must **fail loudly** with a clear error naming the missing file — never fall back to a sheet, and never return an empty or partial plan. (This is the same class of defect as the August faults: an unrecognised column silently defaulting to zero. A silent fallback to a sheet is that failure wearing different clothes — plausible numbers, wrong source.)

3. **Confirm the non-planning paths still read their sheets** and are unaffected — monitoring, corrective re-plan, BOM/kg, machine capacity. Do not disable them.

---

## Add this regression assertion

**Planning-isolation guard:** with Google Sheet access unavailable (simulate an outage / disable the client), the PTMT and Plumbing plans must still build correctly from uploads alone and produce their expected totals. If any plan-build path attempts a sheet read, the assertion fails and names the call site.

This single check makes the rule self-enforcing — it cannot silently regress the way the August column-alias bugs did.

---

## Report

- The full list of data sources in the plan-build path, marked upload or sheet.
- Any fallback-to-sheet branches found and removed.
- Confirmation that monitoring / corrective / BOM / machine-capacity sheet reads are intact.
- New total suite count and pass/fail, including the planning-isolation guard.
