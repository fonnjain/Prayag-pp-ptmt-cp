## PART 2 — Automatic month rollover (the durable fix)

Doing this by hand every month is a standing source of silent staleness. Make the app find the current month's workbooks itself.

**Behaviour:**

- On month change (and on demand via a "Refresh sources" action), the app **searches Google Drive by title pattern** for the current month's workbooks — e.g. `Daily Production PLUMBING <MON> ' <YYYY>`, `5. Pipe & Fitting Plant Date Sheet & Monthly Report - <MON> ' <YYYY>`, `4. PTMT PLAN & ACTUAL - <Mon>-<YY>` — and resolves each to its file ID.
- Match on **title pattern + most recent `modifiedTime`**, and require the month/year in the title to match the planning month. Never fall back to an older month's file.
- **Show the resolved workbook, its ID, its title and its last-modified date in the UI** (the existing workbook-ID config panel), so it's always visible which sheet each feed is actually reading.
- **Keep manual override.** Auto-discovery proposes; a human can pin a specific ID. A pinned ID wins until unpinned.
- **Fail loudly, never silently.** If no workbook matches the current month's pattern, surface a clear error naming the pattern searched — do not fall back to last month's sheet and do not return empty actuals. A missing August sheet must look like an error, not like zero production.
- Log each resolution (month, pattern, chosen file, modified date) so a wrong pick can be traced.

**Guard against the obvious failure:** the app must never silently read a workbook whose title month ≠ the month being planned/monitored. Assert this.

## Regression assertions to add

1. **Month-match guard** — the resolved workbook's title month/year equals the month being monitored; a mismatch fails and names both.
2. **Non-stale guard** — monitoring `totalProduced` and corrective `producedToDate` for the current month are non-zero once production exists; if the resolved sheet yields zero for a month with recorded production, fail rather than report zero.
3. **Cross-source reconciliation** — monitoring `producedToDate` === corrective `producedToDate` for the same as-of date and segment (same source, must agree).
4. **Planning isolation intact** — no planning path reads any of these workbooks (existing guard; confirm still passing).
5. **No-match guard** — when no workbook matches the current month, the app raises a named error rather than falling back to a prior month.
